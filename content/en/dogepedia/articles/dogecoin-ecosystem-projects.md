This is a **non-exhaustive** pointer list — not an endorsement or investment recommendation. Projects appear and change; always verify links and do your own research.

Dogecoin’s “direction” as money is shaped both by [Dogecoin Core](https://github.com/dogecoin/dogecoin) and by tools people actually use. For the difference between Core, the Foundation, and the wider ecosystem, see [Is there a roadmap?](/dogepedia/articles/dogecoin-roadmap).

## Core & protocol

| Project | Role |
|---------|------|
| [Dogecoin Core](https://github.com/dogecoin/dogecoin) | Reference full node and wallet |
| [Dogecoin Improvement Proposals (DIPs)](https://github.com/dogecoin/dips) | Historical / formal proposal archive |

## Libraries & payment rails

| Project | Role |
|---------|------|
| [LibDogecoin](https://github.com/dogecoinfoundation/libdogecoin) | C library for Dogecoin primitives |
| [GigaWallet](https://github.com/dogecoinfoundation/gigawallet) | Backend payment API for merchants/platforms |
| [python-libdogecoin](https://github.com/dogeorg/python-libdogecoin) | Python bindings around libdogecoin |

## Wallets & user apps
